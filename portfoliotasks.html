Week 5

Accessing Data: API and Scrapers

API: UK Inflation Rate

The base URL is: https://api.beta.ons.gov.uk/v1/data. This data was sourced from the UK Office of National Statistics

The elements needed to call the data are the base URL, the timeseries call, the series ID for CPI/Inflation specifically, and the data ID for this particular dataset.

The data is formatted as a JSON file. It is not tidy/cleaned as all the data is stored as text.

The full URL: https://api.beta.ons.gov.uk/v1/data?uri=/economy/inflationandpriceindices/timeseries/d7g7/mm23
